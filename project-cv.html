Portfolio Showcase

HTML CSS VANILLA JS OPENCODE AI ASSISTITO FRONTEND

by Antonio Troiano — autore e codice

/Introduzione

Portfolio statico in HTML, CSS e JavaScript vanilla, senza framework. L'ho progettato e sviluppato con gli agenti AI. Io definisco architettura, requisiti e cosa considero finito. L'agente implementa. Io verifico e correggo.

/Tecnologie_Usate

HTML5

Struttura semantica: hero, sezioni progetto, contenuti navigabili.

CSS modulare

Design tokens. Layout responsive, mobile-first. Un foglio di stile per pagina.

JavaScript vanilla

Effetti di scena, suoni 8-bit con la Web Audio API, piccole interazioni sull'interfaccia.

GitHub Pages

Hosting del sito statico. Deploy dal repository, senza build.

Cursor / OpenCode

Per pianificare, implementare e iterare sul codice. La revisione la faccio io.

/Flow_Operativo

  1. Definisco i requisiti: architettura, file coinvolti, cosa considero finito.
  2. L'agente scrive il piano. Lo revisiono prima di toccare il codice.
  3. Implemento a piccoli step. A ogni step rileggo il diff.
  4. Test su desktop e Android. Correggo finché non fa quello che mi aspetto.
PowerShell — opencode: flow_di_sviluppo

PS C:\WorkSpace\Projects\Personal\CV> opencode

# parte dalla memoria del progetto e valuta la task

PS C:\WorkSpace\Projects\Personal\CV> read progetto_generale.md, stato_attuale.txt, registro_decisionale.md

# struttura: index.html / style.css / script.js

PS C:\WorkSpace\Projects\Personal\CV> analizza le sezioni della pagina progetto

PS C:\WorkSpace\Projects\Personal\CV> implementa modifica proposta → applicata al codice sorgente

# reload nel browser. Stile e interazioni controllati.

PS C:\WorkSpace\Projects\Personal\CV> verifica → stato: tutto ok

# ogni passo aggiorna lo stato. Il registro segna le decisioni.

PS C:\WorkSpace\Projects\Personal\CV> commit "feat: scroll hint sotto la CTA"

// niente librerie, niente build. HTML statico, va su qualsiasi hosting.

/Note

Per lo stile ho scelto un look retrò ma piacevole agli occhi. Il bianco pieno, dopo ore sull'editor, stanca. Grigi caldi, nero quasi pieno, arancio da terminale.

La palette è quella di un terminale, e si legge. Il colore lo uso poco: serve a spostare l'occhio da una sezione all'altra.

Vengo da XR. Sul front-end non ho anni di pratica. La memoria a breve dell'agente, da sola, non bastava. Per questo tengo la documentazione su disco e verifico a mano nel browser. È il mio controllo qualità su ogni passo.

— Antonio Troiano
