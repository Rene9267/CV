# Portfolio XR — Antonio Troiano

## Overview
Personal retro-brutalist CV/portfolio site (sticky-scroll layers) for an XR & Spatial Developer, with polished front page UX.

## Tech Stack
- HTML5 / CSS3 (custom retro-brutalist theme) / vanilla JavaScript
- Web Audio API for retro beep feedback
- Static files, no build tools; served locally with Python http.server
